# Martina

App para el iPad de Martina: **tienda** (inventario, ventas, fiado, recibos por WhatsApp, reportes de ganancia) y **lotería** (jugadas y premios por cliente, comisión del día y lo que hay que entregar).

Se instala desde Safari como app de la pantalla de inicio: https://jean-carlos-declama.github.io/martina/

- Cómo instalarla y usarla: [docs/INSTALAR.md](docs/INSTALAR.md)
- Decisiones técnicas: [docs/DECISIONES.md](docs/DECISIONES.md)

```
npm install
npm run dev     # http://localhost:5173/martina/
npm test        # pruebas
npm run build   # versión para publicar (se publica sola al subir a main)
```
